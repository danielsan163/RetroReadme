# Retro README

Multi-game retro walkthrough app for the Retroid Pocket Nova (1280x960, 4:3, Android 13).
Kotlin + Jetpack Compose, no third-party deps, minSdk 26, landscape only, driven entirely by
D-pad and shoulder buttons. Package `com.retroreadme`. Built on the bones of
https://github.com/danielsan163/MMX2Guide.

Earlier work happened in a claude.ai chat (delivered as zips):
https://claude.ai/share/e3dcd836-b418-4f2d-a27d-e37c1851696d

## Structure

- `core/`: `Game`, `GameTab`, `Platform` (platform order = launcher heading order).
- `games/GameRegistry.kt`: every guide; the launcher groups by platform and sorts titles
  alphabetically, so add new games in any order.
- `games/<id>/`: one folder per guide (mmx2, smw, kdl3, wl4, mzm, mf, sm, mmz, tmc, aos), each with its own
  tabs, content, palette and screens. Checklist progress is stored per game in
  SharedPreferences `progress_<gameId>`. Never change existing checklist ids, or users lose
  their checkmarks.
- Metroid maps (MZM, Fusion, Super Metroid): `games/<id>/<Id>MapData.kt` is generated by
  `tools/metroid-maps/gen.py <game>` from the hand-checked area files in
  `tools/metroid-maps/games/<game>/areas/` (our own drawing, no ripped graphics). The shared map
  model and view are `ui/RoomMap.kt`. Edit the area files and regenerate; never edit a MapData
  file by hand. See the tools README. Room codes (BR-07, S2-14...) follow the 100% route;
  renumbering breaks step text that mentions a code.
- Web version: `docs/` (GitHub Pages) is plain HTML/CSS/JS with no build step. Its data
  (`docs/data/*.json`) is generated from the guide content by the unit test
  `app/src/test/.../web/WebExport.kt`; each guide has an exporter in `GuideExports.kt` that
  mirrors its Compose screens. Never edit `docs/data/` by hand.
- Launcher uses a dark SNES grey/purple palette (`LauncherPalette` in `ui/Theme.kt`); each game
  has its own palette.

## How we work

- The user builds in Android Studio on Windows and tests on the Nova over wireless debugging.
  Say which files changed and whether a Gradle sync is needed or Reload All from Disk is enough.
- Before writing guide content, propose the tab set, checklist scope and palette and get a yes.
- Tone: guides point the way, they don't hand-hold. Say where something is and what it needs in
  a sentence or two; don't narrate every room or turn play into following instructions. The
  existing guides (MMX2, SMW, WL4, MZM) are the right level. Walkthrough steps (e.g. Minish Cap)
  are short "where next" pointers.
- Verify game facts against at least two independent sources. Where only one source covers
  something, add the "worth confirming on the Nova" note on that page and say so.
- After changing any guide content, re-run the web export:
  `gradle :app:testDebugUnitTest --tests com.retroreadme.web.WebExport`. A new guide needs an
  exporter in `GuideExports.kt` (the export fails until it has one); a changed screen needs
  its exporter updated to match.
- Log every user-visible change in `CHANGELOG.md` under the current version
  `versionName` in `app/build.gradle.kts` is still "0.2.0" (released) while the changelog has a
  v0.3.0 section; ask before bumping it.

## Open items (as of 2026-10-08)

- Castlevania: Aria of Sorrow: HP/MP/Heart Max Ups aren't in the checklist yet (they'll be added
  as new entries; the soul ids must stay unchanged), and it still needs a Bosses tab with strategies.
- Metroid: Zero Mission: guide assumes Hard mode items are in the same places; unconfirmed.
- Metroid: Zero Mission maps: Chozodia (ship middle and Ruins maze) is the least certain
  transcription; check room splits against the in-game map. Item steps cite room codes, so
  re-check those steps if a room is split, merged or renumbered.
- Metroid Fusion: in a few rooms several tanks fit the sources' descriptions (Sector 4's middle
  rooms, Sector 5's west side); confirm which is which in a playthrough. Main Deck Missile Tanks 1
  and 2 are marked worth confirming (only Recon says they're one-chance pickups).
- Super Metroid maps: extracted automatically from Falcon Zero's map, so room splits are only as
  good as that drawing. Least certain: which Ridley's Lair missiles are Missile Tanks 13 and 15
  (NO rooms near the east), and Brinstar Missile Tank 2 (Recon says it's reachable early, Budwin
  used a Power Bomb; marked worth confirming). Tourian has no items, so no map.
- Mega Man Zero: boss strategies for Harpuia, Leviathan, Hanumachine, Herculious, the Rainbow Devil
  and Copy-X rest mostly on the Mega Man Knowledge Base (StrategyWiki's pages are stubs there).
  Aztec Falcon's weakness is disputed (one source says Ice), so it's shown as none.
- The Minish Cap: four upgrades are marked worth confirming (Stockwell's shop wallet, bomb bag and
  quiver, and Fifi's bottle: only Zelda Wiki covers them). Tiger Scrolls and Figurines aren't on
  the checklist; walkthrough step ids (w01...) are stored like checklist ids but aren't in
  `Game.checklist`, so they don't count toward 100%.
